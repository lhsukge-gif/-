# AI 알지만 실습터

「AI 알지만 (알고, 지키고, 만드는) 디지털 시민 교육」 6차시 실습 웹앱입니다.

- `index.html` 파일 하나로 동작하는 정적 사이트입니다. 서버·빌드 없이 브라우저에서 열 수 있습니다.
- 홈: 차시별 **실습 시작** 버튼과 캔바 **학습교안** 버튼. 차시를 완료하면 마을의 집에 불이 켜집니다.
- 차시 화면: 슬라이드 흐름을 따른 단계 레일 + 퀴즈·O/X·분류·순서·찾기·빈칸·프롬프트 빌더·점검표 활동.
- 학생 입력은 해당 기기 브라우저(localStorage)에만 저장되고 외부로 전송되지 않습니다.

## 배포
GitHub Pages, Netlify, Vercel 등 정적 호스팅에 `ai-alziman` 폴더를 그대로 올리면 됩니다.

## 내용 수정
`index.html`의 `const L = [...]` 배열이 6차시 데이터입니다. 캔바 링크는 각 차시의 `canva`, 패들렛 주소는 `PADLET` 상수에서 바꿉니다.
